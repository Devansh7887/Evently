# 🎟️ Evently — Full Stack Event Management & Ticket Booking Platform

Evently is a full-stack event management and ticket booking web application designed to handle the complete lifecycle of an event — from creation and management to user registration, ticket booking, and payment confirmation.

The platform includes user-facing features, a secure admin dashboard, email notifications via SMTP, and payment gateway integration, making it suitable for real-world event management use cases.


## 🚀 Features

###  User Side
- Browse and explore available events
- View detailed event information
- Book tickets for events
- Secure online payment integration
- Email confirmation after successful booking
- Responsive UI for smooth experience across devices

### 🛠️ Admin Dashboard
- Create, update, and delete events
- Manage event details, pricing, and availability
- View and manage user bookings
- Monitor payments and transactions
- Centralized control over the entire platform

### 📧 Email & Payments
- SMTP integration for automated email notifications
- Payment gateway integration for secure transactions
- Booking confirmation emails sent to users
